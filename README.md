# ミリプロ推しガチャ

ミリプロメンバーを引いて集める非公式ファンメイドガチャです。

## UI / 演出
- Claude Artifact版の濃紺フェルト + 金アクセントのデザインをベースに採用
- 単発 / 10連
- パック開封演出（切り取り線を右へスワイプ、またはタップで開封）
- SSR入りは開封前に金の光が漏れる予兆
- 推しSSR入りはピンクの予兆 + 強めのハプティクス
- 開封後はカードを1枚ずつめくる
- SSRは全画面演出
- prefers-reduced-motion に対応
